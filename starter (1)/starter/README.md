# Граф денежных переводов

## Запуск анализа

Требуется **Python 3.12.10** (версия также записана в `.python-version`). Установите зависимости и запустите из папки `starter`:

```bash
py -3.12 -m pip install -r requirements.txt
py -3.12 starter.py --data "../../data (1)/data" --out ./output
```

Создаются `node_metrics.csv`, `nodes_roles.csv`, `clusters.csv` и `top_nodes.csv` в `output/`.

`node_metrics.csv` — единый набор признаков по каждому `gid`: степени, объемы, число транзакций, число контрагентов, доля проходящих средств, PageRank, betweenness, depth, seed и признак обрезки на глубине.

## Интерфейс

После генерации CSV:

```bash
py -3.12 -m streamlit run app.py
```

Во вкладке Graph можно ввести любой GID из выгрузки и увидеть роль, оценку приоритета, кластер, числовое обоснование и локальные связи.

## Тесты

После генерации CSV запустите:

```bash
py -3.12 -m unittest discover -s tests -v
```

Тесты проверяют покрытие всех GID, согласованность агрегатов, обязательные схемы CSV, диапазоны оценок, сортировку top nodes, правила для `depth=4` и seed-узлов, а также запуск Streamlit.

## Интерпретация ограничений

- `depth=4` — предел извлечения данных. Для узлов на глубине 4 без исходящих ребер выставляется `truncated_by_depth=True`; они не классифицируются как `terminal`.
- У seed-узлов история входящих переводов неполна. Их `pass_through` оставляется пустым и этот показатель не используется для классификации.
- Сообщества считаются на неориентированной проекции, с суммой объемов как весом. Направление сохраняется в метриках и визуализации.
- Роли и priority — объяснимые эвристики, а не подтверждение незаконной деятельности. Проверяйте evidence и исходные связи.
